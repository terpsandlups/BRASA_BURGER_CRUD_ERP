# Anexos explicativos

Esta pasta acompanha a versão revisada do trabalho escrito.

- `memoria-de-calculo.md`: fórmulas, unidades e exemplos verificáveis.
- `casos-de-teste.csv`: cenários propostos, com resultados esperados. Todos estão como não executados nesta revisão.

O pacote não apresenta testes ilustrativos como testes da aplicação real. Código demonstrativo e diagramas antigos que possam divergir da arquitetura atual não foram incorporados como evidência de implementação.

As modelagens algorítmica, matemática e orientada a objetos estão desenvolvidas no trabalho escrito; a arquitetura também é apresentada nos slides. Os registros de execução, capturas atuais e diagramas adicionais devem corresponder à versão publicada do código.

Para registrar uma execução, informar commit, ambiente, data, entradas e resultados observados. Somente depois alterar o status de um teste para aprovado ou reprovado.
